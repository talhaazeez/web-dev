FAQ

Remote design collaboration questions

Can customers review a 3D design without SolidWorks?

A secure browser-based review can let external stakeholders inspect the selected design without installing SolidWorks, subject to the workspace permissions.

Can suppliers see only selected files?

Teams can share specific projects, files, or versions and use access controls so external partners see the information needed for their review.

How does collaboration stay tied to the right version?

Version control and browser reviews work together so feedback and decisions can be associated with the design version being reviewed.

Answer-ready summary

What remote SolidWorks collaboration should preserve

Short answer: Remote collaboration works when the team shares the same controlled design context, not when engineers repeatedly export screenshots and STEP files. Sibe connects SolidWorks version control with browser-based views for the people who need to review or act on the product definition.

Problem

Review by attachment

Email chains and screenshots can separate feedback from the design version that prompted it.

Solution

Role-appropriate access

Engineers continue in SolidWorks while project managers, customers, suppliers, quality teams, and reviewers use selected browser views.

Proof point

No VPN project

The product is positioned around cloud access for distributed work without requiring a customer-managed PDM server and separate VPN project.
