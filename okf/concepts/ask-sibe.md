# Ask Sibe informational endpoint

Ask Sibe provides read-only informational answers about public Sibe CAD content, including cloud CAD management, SolidWorks version control, BOM workflows, browser collaboration, trial details, pricing links, security links, and contact options. It does not access private workspaces, create accounts, process payments, change subscriptions, or perform destructive actions.
